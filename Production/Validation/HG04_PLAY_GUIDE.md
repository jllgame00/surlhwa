# HG04 — play the ACT 1 excerpt

Open [the Windows Player](Builds/Slice/SurlhwaSlice.exe). C1 remains the accepted spatial baseline. The environment and inherited character/audio assets remain provisional.

This is a disclosed Warmth-follow-up excerpt: the postman visits first, then Little Prince. It does not complete ACT 1 or award any memory. Seolya and Manhattan are explicitly known; an unnamed recipe's learned facts can lead to Dry Martini. A mismatch can still reveal that drink.

Start a new excerpt or Continue. Enter or the on-screen Continue button advances one reading step. B opens Guide, Tab opens Codex, Escape opens settings or closes the top panel. The Guide gives the available recipe facts.

| Control | Action |
| --- | --- |
| 1–8 / ingredient shelf | Select a supplied ingredient |
| Q / hold Pour | Pour into the selected target |
| Shift while pouring / Fine toggle | Pour slowly |
| E / hold Jigger transfer | Empty the jigger into the mixing glass |
| J / Target | Cycle jigger, mixing glass, serving glass |
| I / Ice | Add ice to the selected target |
| S held + circular mouse motion around mixing glass | Stir; liquid and ice are required |
| R / hold Strain | Transfer mixing glass into serving glass |
| D / Dash | Add a measured game dash of the selected ingredient |
| C / Cherry | Put a cherry in the serving glass |
| V / Serving glass | Change serving shape; liquid recognition stays independent |
| Current glass discard | Clear only the current preparation; preserve story/knowledge |
| Serve button | Commit the actual drink, then read reaction and result |

The spoon follows accepted circular movement. Loops stop on release or a panel interruption. Closing a panel does not resume a held tool automatically. Slight and flat tool presentation are available for the same preparation state; this does not reopen C1.

On save failure, Retry or Return to saved record is available by pointer or keyboard selection/Enter. Continue restores the last durable reading/outcome; an interrupted preparation restarts empty. New Game confirmation replaces only the isolated Slice record; sound/readability settings remain.

HG04 review concerns whether measuring, pouring, stirring and straining are understandable and comfortable. Final art, later UI/audio/narrative gates, campaign completion and final game readiness are not approved by this build.
