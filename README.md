# 설화 (SURLHWA)

눈 내리는 밤, 작은 바에서 손님의 이야기를 듣고 한 잔으로 마음을 건네는 Unity 게임입니다. 효율과 점수 경쟁보다 듣고, 기억하고, 다시 만나는 경험을 지향합니다.

현재 범위는 **18번의 밤, 47회 만남**으로 구성한 첫 전체 캠페인입니다. 어린왕자, 춘향·몽룡, 돈키호테, 햄릿, 파우스트, 심청, 오디세우스의 주 ACT와 일반 손님의 일상이 하나의 엔딩으로 이어집니다. 기존 네 밤의 5 / 4 / 4 / 4회 만남은 캠페인의 시작부로 유지합니다.

설야·만월과 IBA 칵테일 7종을 다룹니다. 기존 드라이 마티니·네그로니·맨해튼·진 피즈에 이어, 일반 손님을 통해 6밤 행키 팽키, 10밤 프렌치 75, 15밤 라스트 워드를 배웁니다. 새 레시피는 대화에서 배운 재료·용량·준비 순서를 실제로 시도하며 기록합니다. 추천 요청에서는 배운 술 가운데 손님의 마음에 어울리는 잔을 고릅니다.

## 실행

로컬 빌드 산출물: `Builds/Windows/SURLHWA.exe`. 실행 파일과 `SURLHWA_Data`, DLL 등 **폴더 전체를 함께** 보관하세요. Unity 설치 없이 실행할 수 있습니다. 검토 기준은 16:9, 1280×720 및 1920×1080입니다. 다른 화면 비율은 아직 검증하지 않았습니다.

- **새 게임**: 기존 게임 진행을 초기화하고 첫날부터 시작합니다. 음량 설정은 유지합니다.
- **이어하기**: 저장된 밤과 레시피 지식·주요 방문 기록을 불러옵니다. 5밤부터는 마지막 손님이 떠난 지점까지 저장합니다. 진행 중이던 대화나 조주는 해당 만남의 처음부터 다시 시작합니다.
- 18밤의 마지막 손님 이후 엔딩을 읽습니다. 엔딩 도중 종료하면 처음부터 다시 읽을 수 있고, 다 읽은 뒤 이어하기는 마지막 마감으로 돌아옵니다. 19밤은 생성하지 않습니다.
- 기존 완료한 네 밤 데모 저장도 5밤으로 이어집니다. 어린왕자의 방문 결과나 배우지 않은 레시피를 임의로 성공 처리하지 않습니다.
- 종료는 Windows 창 닫기 또는 Alt+F4를 이용하세요.

## 조작

| 상황 | 조작 |
|---|---|
| 손님과 대화 | 손님 표시 클릭 → 다음 / 선택지 |
| 조주 시작 | 조주 버튼, 추천 요청에서는 방식 선택 후 확인 |
| 레시피 확인 | 조주 화면의 레시피 버튼. 읽는 동안 조주가 멈춥니다. |
| 재료 붓기 | 선반에서 재료 클릭 후 Space 누르기 / 놓기 |
| 얼음 / 대시 | I / D (준비 단계) |
| Stir | 얼음 → 젓기 시작 → 잔 둘레로 마우스를 원형으로 움직이기 → 젓기 마치기 → 걸러 따르기 |
| Shake | 얼음 → 흔들기 시작 → A 또는 ← / D 또는 → 박자 → 걸러 따르기 또는 P로 옮겨 붓기 |
| Build | 서빙 잔에 직접 붓기 → 마무리 |
| Float | 재료를 순서대로 붓기. Shift는 천천히, Ctrl은 세게 붓기 |
| 추가 준비 | 지원 단계에서 S: 스플래시, J: 가볍게 젓기 |
| 가니시 | 1–6: 종류, Q/W/E: 테두리/잔 안/표면, G: 올리기, X: 빼기 |
| 소리 설정 | 처음 화면 또는 Esc. 전체/음악/효과·바람 음량과 음소거 |

재료의 실제 양, 순서, 조주 결과로 완성된 술을 판정합니다. 레시피북을 선택하는 것만으로 술이 만들어지지 않습니다. 요청에 어울리는 술이어도 조주에 실패하면 어린왕자의 성공한 방문으로 기록되지 않습니다.

## 개발과 검증

Unity **6000.3.7f1**, 기본 브랜치 `refactor/project-rebuild`.

1. Unity에서 프로젝트를 열고 `Assets/_SURLHWA/Scenes/Gameplay/BarScene.unity` 실행.
2. `SURLHWA/Validation` 메뉴에서 분야별 검증 실행.
3. 명령행 컴파일: `dotnet build Assembly-CSharp-Editor.csproj --no-restore`.
4. 전체 정적·Editor 회귀: `SURLHWACampaignValidation.RunIntegrated`.
5. 전체 캠페인 Play Mode: `SURLHWACampaignPlayModeValidation.Run` 또는 조용한 작별·만월 복구를 포함하는 `RunQuiet`. 첫 네 밤의 두 작별·실패 재시도 회귀는 `SURLHWAFourNightPlayModeValidation.Run`.
6. Windows 검토 빌드: `SURLHWA/Build/Windows Review Campaign` 또는 `SURLHWAWindowsBuild.Run`.
7. 직접 플레이 확인: [검토 체크리스트](Docs/RELEASE_REVIEW.md).

통합 검증은 실제 운영 UI 콜백과 조주 입력 처리 지점을 구동합니다. 물리 마우스·키보드 사용감, 대사 호흡, 화면 미감과 소리 믹스의 최종 승인을 대신하지 않습니다.

## 검토 상태

캐릭터·칵테일 그림과 음원은 **검토용 초안**입니다. 새 특수 손님은 기존 캐릭터 실루엣을 임시로 사용합니다. 바의 기억은 작은 윤곽 오브젝트로 표현하며, 재회에는 두 사람과 공유하는 잔 하나를 표시합니다. 전용 캐릭터 아트·앉은 자세, 가니시/잔 세부 묘사, 기억의 최종 미술과 소개 영상은 후속 작업입니다. 대사·호흡·조작감·전체 감정선은 소유자의 전체 플레이 후 다듬습니다.
