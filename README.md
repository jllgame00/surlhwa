# 설화 (SURLHWA)

눈 내리는 밤, 조용한 바에서 손님에게 칵테일을 내어주고
그들의 이야기를 듣는 스토리 중심 힐링 바텐딩 게임입니다.

---

## 게임 소개

**SURLHWA**는 경영 효율이나 돈 관리보다
분위기, 감정, 대화, 그리고 칵테일을 만드는 과정에 집중하는 2D 바 운영 게임입니다.

플레이어는 설원 속 작은 바의 바텐더가 되어
찾아온 손님에게 칵테일을 만들어 내어주고,
손님의 감정에 어울리는 술을 통해 이야기를 이어갑니다.

이 게임에는 강한 실패 페널티나 복잡한 자원 관리가 거의 없습니다.
대신 **명성(Reputation)**, **감정 태그**, **레시피 발견**, **손님 반응**이 진행의 중심이 됩니다.

---

## 핵심 플레이 흐름

```text
손님 등장
→ 좌석 착석
→ 상호작용 표시
→ 대화 진행
→ 조주 방식 선택
→ 미니게임 진입
→ 레시피북 확인
→ 재료 선택 및 지거 계량
→ 칵테일 제조
→ 레시피 매칭
→ 손님 반응
→ 레시피 해금
→ 명성 변화
→ 손님 퇴장
```

플레이어는 단순히 정답 메뉴를 고르는 것이 아니라,
실제로 선택한 재료와 비율을 바탕으로 칵테일을 완성합니다.

---

## 주요 시스템

### 손님 시스템

- 손님 스폰 및 좌석 배정
- 손님별 상호작용 UI 표시
- 대화 패널을 통한 주문 흐름
- 손님 감정 태그 랜덤 배정
- 칵테일 감정 태그와 비교한 반응 처리
- 하트 팝업 및 퇴장 연출

### 조주 방식 선택

현재 네 가지 조주 방식이 구현되어 있습니다.

- Stir
- Shake
- Build
- Float

플레이어는 BrewPanel에서 조주 방식을 선택한 뒤,
각 방식에 맞는 미니게임으로 진입합니다.

### 미니게임

각 미니게임은 바로 시작되지 않고,
먼저 Preview 상태에서 레시피북과 재료 선택 UI를 확인할 수 있습니다.

구현된 미니게임:

- Stir MiniGame
- Shake MiniGame
- Build MiniGame
- Float MiniGame

### 레시피 시스템

- `CocktailRecipeData` 기반 레시피 데이터
- 조주 방식별 레시피 분리
- 재료 ID와 비율 기반 레시피 매칭
- `RecipeMatchService`를 통한 유사도 계산
- 성공 시 해당 칵테일 데이터로 손님 반응 처리

레시피북은 “선택해서 만드는 메뉴”가 아니라,
플레이어가 참고하는 가이드 역할을 합니다.

실제 판정은 플레이어가 만든 `BrewComposition`을 기준으로 이루어집니다.

### 재료 선택 및 지거 시스템

미니게임 Preview 단계에서 재료 선반을 통해 재료를 선택할 수 있습니다.

현재 구현된 기능:

- IngredientShelfPanel
- 재료 목록 정렬
- 재료별 amount 표시
- JiggerPanel
- 선택한 재료 표시
- +0.5 / +1.0 / Clear를 통한 계량 조절
- 지거 이미지 피드백 애니메이션
- Start 시 선택된 재료량을 `BrewSessionData`로 변환

이 구조는 추후 실제 지거 붓기 연출과 자연스럽게 연결될 예정입니다.

### 레시피 해금

- 미해금 레시피 매칭 성공 시 레시피 해금
- 해금 팝업 출력
- PlayerPrefs 기반 해금 상태 저장
- 재실행 후에도 해금 상태 유지

### 명성 시스템

- 미니게임 결과와 주문 결과에 따라 명성 변화
- 명성은 이후 특별 손님 등장과 스토리 진행에 활용될 예정입니다.

## 개발 철학

> 이 게임은 효율을 요구하지 않는다.
> 머무르고, 듣고, 천천히 한 잔을 내어주는 게임이다.

SURLHWA는 플레이어가 빠르게 돈을 벌거나 최적화를 반복하는 게임이 아니라,
조용한 바 안에서 손님의 감정과 이야기에 귀 기울이는 경험을 목표로 합니다.
