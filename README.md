# surlhwa

조용한 바에서 손님에게 술을 내어주고,  
이야기를 듣는 **스토리 중심 힐링 게임**.

---

## 게임 소개

**surlhwa**는 경영이나 효율을 요구하지 않는  
분위기와 서사 중심의 바 운영 게임입니다.

플레이어는 눈 내리는 어느 바의 바텐더가 되어  
손님들에게 술을 내어주고,  
명성이 쌓일수록 특별한 손님들을 만나게 됩니다.

이 게임에는 돈 관리나 실패 페널티가 거의 없습니다.  
대신 **명성과 감정의 흐름**이 모든 진행을 결정합니다.

---

## 핵심 플레이 루프 (현재 구현)

- 손님 등장
- 좌석 착석
- 주문 발생
- 플레이어가 서빙
- 명성 증가
- 손님 퇴장

> 이 루프는 이후  
> 스토리, 연출, 미니게임으로 자연스럽게 확장될 예정입니다.

---

## 현재 구현 상태

- 손님 스폰 및 좌석 배정 시스템
- 주문 → 서빙 → 퇴장 흐름
- 명성(Reputation) 시스템
- 최소 UI (텍스트 기반)

---

## 향후 계획

- 명성 기준 특별 손님 등장
- 스토리 분기형 대화 시스템
- 칵테일 미니게임 (쉐이킹 / 스터)
- 명성에 따른 바 분위기 변화
- 멀티 엔딩 구조
